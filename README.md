# Làng Ven Núi

Bản thử nghiệm game idle pixel trên taskbar Windows do Pearl thực hiện.

1. Mở [Lang-Ven-Nui-Windows.zip](./Lang-Ven-Nui-Windows.zip) và tải tệp từ GitHub.
2. Giải nén toàn bộ ZIP vào một thư mục.
3. Chạy `VillageOverlay.exe` và giữ các tệp DLL đi kèm trong cùng thư mục. Nếu Windows yêu cầu, cài .NET Desktop Runtime 8.

Gói tải gồm bản chạy thử Windows.
